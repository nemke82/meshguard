Features

What works today, and what is coming

Every feature is marked by where it stands. Available means it is in the release you can download. Anything still being built or tested is labelled that way, without dates.

  • Available In the current release
  • New New in the latest release
  • In development Being built

Messaging

Messaging features
FeatureStatusSinceDetails
Encrypted one-to-one messaging Available v2026.11.14 AES-256-GCM on your device, bound to sender and recipient. Up to 173 bytes per message, sent as one packet.
Delivery confirmations Available v2026.11.14 ✓ your radio has it; ✓✓ your contact’s MeshGuard confirmed it with an encrypted acknowledgement (2.0 mode).
Duplicate and replay protection Available v2026.11.14 Every message has its own ID, time and lifetime. Relayed copies show once; a recorded message cannot be played back later (2.0 mode).
Works with older versions Available v2026.11.14 Turn off MeshGuard 2.0 mode when pairing to chat with someone on an older version. A 2.0 chat is never silently downgraded.
Message history New v2026.11.16 Conversations are kept on the device, encrypted, until you delete them. A chat list shows the last message and unread count.
Unsent messages kept and resent New v2026.11.16 A message written while the radio is away waits and goes out when the radio is back, with pauses between attempts.

Pairing and contacts

Pairing features
FeatureStatusSinceDetails
Offline QR pairing Available v2026.11.14 Meet in person and scan a code: a random key, no passphrase to type. Typing the code works too.
Passphrase pairing Available First release Both people enter the same passphrase (at least 8 characters). It is never stored or sent.
Remembered chats Available v2026.11.14 Chat keys are saved, encrypted with a random device key that the Android Keystore protects, so you do not pair again. On Linux and macOS, with the system keyring, since v2026.11.16.

Family and safety

Family and safety features
FeatureStatusSinceDetails
Family check-ins Available v2026.11.14 “I’m OK”, “On my way”, “I need help” with one tap; the wording is yours to change.
Share location Available v2026.11.14 Sends the radio’s last GPS position with its accuracy and age. Needs a radio with GPS and a fix.
SOS with location Available v2026.11.14 Goes to all paired contacts, who see a full-screen alert. Delivery depends on range and relays. Does not contact emergency services.

MeshGuard is not an emergency service. An SOS reaches only your paired contacts, and only if the radios can reach each other.

Radio and connection

Radio and connection features
FeatureStatusSinceDetails
Bluetooth connection and auto-reconnect Available v2026.11.14 Reconnects to the last radio when the app starts and when the radio comes back, while the app is running.
Wi-Fi (TCP) radios Available First release Connect to a radio on your local network. Since v2026.11.15 MeshGuard also finds such radios on its own and remembers them. Local network only, no internet.
USB serial Available First release Connect a radio with a cable on Linux and macOS.
Mesh diagnostics Available v2026.11.14 Last heard, hops, RSSI and SNR, battery and channel use when the node reports them, signal history, and path tests.

In development and planned

Features in development and planned
FeatureStatusSinceDetails
Messages with the app closed (Android) In development — A background service that keeps the radio connection while MeshGuard is closed. The current release only contains a test switch for it.
Reply from a notification In development — Answer a message from the Android notification without opening the app.
Group conversations Planned — Today every conversation is between two people. SOS and check-ins can go to several contacts.
Home-screen widget and Quick Settings tile Planned — One-tap check-in from outside the app.
Home gateway Planned — An optional Raspberry Pi with a LoRa radio on your home network, so a phone does not need to stay near its radio.
Automatic switching between connections Planned — Today you choose Bluetooth, Wi-Fi or USB yourself; MeshGuard does not switch between them on its own.
Voice and push-to-talk Not planned — Not planned for LoRa, which is far too slow for voice. Any voice-radio work would be a separate, experimental project.

See the roadmap for how these fit together.

Platforms

Android

Android 8.0 or newer. The main platform, and the one the setup guide covers.

Linux

Ubuntu/Debian (.deb), Fedora/RHEL (.rpm) and a universal AppImage. Bluetooth through BlueZ.

macOS

One app for Apple Silicon and Intel Macs.

Full release notes: changelog.

MeshGuard

Free, open-source, privacy-first messaging for Meshtastic LoRa radios. No account, no servers.
