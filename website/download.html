Download

Download MeshGuard

Free and open source under the MIT license. Every download comes from the project’s official GitHub release.

Android

Android 8.0 or newer (64-bit and 32-bit ARM, x86_64).

Download APK

Allow your browser or file manager to install apps when Android asks. A listing in the IzzyOnDroid F-Droid repository is being prepared.

Linux

Ubuntu/Debian, Fedora/RHEL, or a universal AppImage (x86_64).

.deb / .rpm / .AppImage

Debian/Ubuntu: sudo dpkg -i meshguard_*.deb
Fedora/RHEL: sudo dnf install meshguard-*.rpm
AppImage: chmod +x meshguard-*.AppImage, then run it.

macOS

One app for Apple Silicon and Intel Macs.

Download .dmg

Open the .dmg and drag MeshGuard to Applications.

Check your download

Each release lists a SHA-256 checksum for every file in SHA256SUMS.txt. Put it next to your download and run:

sha256sum -c --ignore-missing SHA256SUMS.txt

On macOS use shasum -a 256 -c --ignore-missing SHA256SUMS.txt.

What changed

Release dates are the version numbers, for example v2026.11.16. See what is new in each one in the changelog, or browse all releases.

New here? Read the setup guide before you install.

Build from source

git clone https://github.com/nemke82/meshguard.git
cd meshguard/ui && npm install && cd ..
cargo tauri dev

Requires Rust, Node.js 20+ and the Tauri CLI. The README lists the system packages for each platform and the Android build steps.

MeshGuard is not in any app store yet. Download it only from the official GitHub releases linked on this page.
