Supported hardware

Radios, phones and computers

MeshGuard talks to standard Meshtastic firmware, so most Meshtastic radios should work. Below is what the project tests itself, and what is expected to work but has not been verified.

Radios

Radio compatibility
RadioStatusNotes
Seeed SenseCAP T1000-E Tested The project’s reference radio, used in every two-radio test. Built-in GPS. No screen, so it uses a fixed Bluetooth PIN (123456 by default).
LilyGO T-Beam / T-Beam Supreme Compatible, not verified Standard Meshtastic firmware. GPS on most versions.
Heltec LoRa 32 V3, Wireless Tracker Compatible, not verified Radios with a screen show a random Bluetooth PIN on the display when you connect.
RAK WisBlock (RAK4631) Compatible, not verified GPS only with the GPS module fitted.
Station G2 and other Meshtastic radios Compatible, not verified Any radio running Meshtastic firmware 2.x with Bluetooth, Wi-Fi or USB should work.

Tried MeshGuard on another radio? Tell us how it went, so this list can grow.

Requirements

Radio firmware and settings

  • Meshtastic firmware 2.x. Hop counts in diagnostics need 2.3 or newer.
  • The same region, modem preset and primary channel on every radio that should talk to each other.
  • A region setting that is legal where you use it.

Phones and computers

  • Android 8.0 or newer with Bluetooth LE.
  • Linux with BlueZ for Bluetooth, or a USB or Wi-Fi connection to the radio.
  • macOS on Apple Silicon or Intel.
  • One phone or computer per radio. A radio connects to one app at a time.

GPS and location

Location in check-ins and SOS comes from the radio, so it needs a radio with GPS (or a fixed position set on the radio) and a current fix. A first fix outdoors can take several minutes; indoors it may never come.

Range

There is no fixed range. Line of sight, height, antennas, the modem preset and nearby relay nodes all matter. A pocketed radio in a city reaches far less than one on a hill. Test where you plan to use it.

Radio rules differ by country. You are responsible for using a region, power and antenna that are allowed where you are.
